# 未来战争 Future War

经典红警玩法的现代武器版浏览器 RTS：单人遭遇战，蓝军（玩家）vs 红军（AI）。
采矿经济、电力系统、基地建造、坦克海推进，武器装备全面现代化。
超级武器、机甲、中立争夺、燃烧残骸、HDR 后处理渲染、卷积混响音效，全部离线运行。

> 📋 升级轨迹 / 关键修复 / 后续计划见 [PROGRESS.md](PROGRESS.md)

## 运行

需要一个静态文件服务器（ES Modules 不能用 file:// 打开）。**请用内置的 `server.py` 启动**（带 no-cache 头，避免浏览器缓存新旧混合的代码导致逻辑错乱）：

```bash
npm start          # = python3 server.py（端口 8000）
# 然后浏览器打开 http://localhost:8000/
```

> 升级代码后如果行为异常（点了没反应/画面假死），先强制刷新一次（Cmd/Ctrl+Shift+R）清掉旧缓存。
> 窗口被其他窗口完全遮挡或切到后台标签时游戏会自动暂停（顶栏显示 ⏸），回到前台自动继续。

## 玩法

- 目标：歼灭红军全部建筑与单位（或自己被歼灭）
- 经济：采矿车自动采金矿运回精炼厂，资金是唯一资源
- 电力：电厂供电，供不应求时生产减速、防御塔停摆
- 科技树：兵营 → 战车工厂 → 雷达站 → 高级单位/建筑
- **科技研发**（雷达站-科技页签）：精准弹药（火力+20%）/ 复合装甲（减伤17%）/ 引擎强化（机动+25%）/ 采矿优化（采矿+30%），一次研发全军永久生效，AI 也会研发
- **超级武器「轨道动能炮」**：研发「轨道打击授权」（需核电站+雷达站）后解锁，V 键/侧栏按钮全图锁定落点，1.7s 预警后天降毁灭打击（冷却 180s）；困难 AI 也会研发并对你的基地反击
- **泰坦重型机甲**：双足行走机构（腿部摆动动画）+ 双联电磁轨道炮的终极地面单位，困难 AI 后期也会投产
- **中立补给站**：地图中场两座无主建筑，派工程师占领后每 5s +$100 持续收入——AI 也会出工程师争夺
- **无人修理厂**：范围内友军地面载具自动维修（按耐久扣费），前线续航关键
- **狙击手光学迷彩**：不开火时隐形（敌人无法索敌），开火/受击短暂现形
- **老兵系统**：单位击杀积攒经验自动晋升（Lv2/Lv3），火力 +15%/级、耐久 +20%/级，头顶金色袖标
- **载具残骸**：被击毁的坦克留下燃烧残骸，缓缓烧尽淡出
- 三档 AI 难度：简单（6min 首波/5min 间隔·新手保护） / 普通（3.5min/2.3min） / 困难（2min/70s 坦克海），AI 会回防基地、见你出空军就补防空、占中立、放超武（**敌方超武有全图预警+警报横幅，给你 1.7s 疏散**）
- **作战微操**：混合框选自动过滤矿车、防空优先打空、火炮被贴脸自动拉扯、矿车被打逃向精炼厂、部队防叠分离、大兵团寻路拉直+短距直连
- **多工厂并行加速**：每多建一座兵营/战车工厂，该线生产速度 +35%（上限 170%）——扩张经济直接转化为爆兵速度
- **阵营专属兵种（超越原作的对称克制）**：
  - 红军专属：**磁暴线圈**（防御塔，链式电弧跳 3 目标+麻痹 1.5s）、**基洛夫重型飞艇**（1400HP 空中堡垒投弹）、**天启突击坦克**（四联炮管+可对空导弹的全能重坦）
  - 蓝军专属：**光棱坦克**（折射束一打三，群伤清场）、**幻影坦克**（静止时幻化成一棵树，开火现形，伏击神器）

### 演示模式

`http://localhost:8000/?demo=1` 自动建造、持续出兵并循环进攻（可作自测，手动操控相机即停止跟随）；
`&ff=N` 加载后同步快进 N tick（无头截图验证用）；
`?demo=1&scene=battle` 直接摆一场坦克遭遇战看特效；
`&diff=hard` 指定 AI 难度；`?lowfx` 关阴影/后处理（弱机或无头验证）。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 点建造按钮扣了钱但什么都不出 | 游戏循环被冻结（旧版本在窗口被遮挡时会假死）。已修复：遮挡时定时器接力驱动 + 切后台自动暂停；请刷新加载最新代码 |
| 生产完成但建筑放不下 | 放置需要：落点全为草地 + 距己方建筑 ≤2 格。看绿色/红色幽灵预览 |
| 造了兵营/工厂却生产很慢 | 电力不足（顶栏电力条变红）：补燃气电厂/核电站 |
| 升级后行为诡异 | 浏览器缓存了新旧混合的 JS。用 `npm start`（server.py 强制 no-cache）+ 强刷一次 |

## 技术

- 模拟层（`src/sim/`）纯逻辑零 DOM 依赖，可无头测试
- 渲染层为 Three.js 低多边形 3D（`vendor/three.module.min.js` 本地内置，离线可玩）：
  - 手写 HDR 后处理管线（Bloom + ACES 色调映射 + 冷暖分级 + 晕影 + 胶片颗粒）
  - **程序化建模材质**：Canvas 生成金属面板（蒙皮缝/铆钉/锈渍流挂）、混凝土、迷彩、警示条纹、木板纹理；坦克为真实行走装置（负重轮/主动轮/诱导轮），配遥控武器站、烟幕弹发射器、热成像仪、爆反装甲等现代细节；泰坦机甲双足腿部关节摆动、步兵双腿走路动画、载具悬挂晃动；PMREM 渐变天光环境反射 + 漂移云影层
  - **序列帧爆炸**：Canvas 程序生成 10 帧火球翻滚图集 + 枪口焰序列帧 + 火花/浓烟粒子 + 冲击波环 + 焦土贴花；超级武器天顶充能光柱 + 落点警示环（_renderOrder 高于战争迷雾，全图可见）+ 载具燃烧残骸
  - 程序化地形贴图（双线性 value noise 草地/矿脉晶簇/水岸沙边）、着色器动态水面、渐变天空穹顶
  - 战场道具：弹药箱/油桶/沙袋掩体点缀；爆炸驱动的相机震动、受击闪白、脉冲选中环、老兵金袖标、狙击手迷彩半透明
- 音频为纯 WebAudio 现场合成（`src/audio.js`，无音频文件）：
  - **电影级分层音色**：瞬态裂纹 + 主体轰鸣 + 次低音 + 余烬滚雷 + 碎裂噼啪，经生成式脉冲响应卷积混响；超级武器专属充能爬升音与史诗落点爆响
  - 空间化：声像 + 距离衰减 + 距离低通（越远越闷）+ 每次开火随机音高/响度抖动；大爆炸自动闪避压低音乐
  - 自适应配乐：鼓/贝斯/琶音/失谐弦垫随战场烈度分层，A 小调军事合成循环
- 地表与战争迷雾为 Canvas 贴图，小地图带雷达扫描线与受击警报 ping

## 结构

```
src/config.js     全部平衡数据（改数值调平衡都在这里）
src/sim/          纯逻辑：世界/寻路/经济/战斗/AI（不依赖 DOM）
src/render/       渲染器/后处理/粒子/蒙皮纹理/3D 模型库/输入/建造栏 UI/小地图
src/audio.js      WebAudio 合成音效引擎 + 自适应配乐
src/demo.js       演示模式（可选加载）
vendor/           three.js r160（本地化）
test/smoke.mjs    无头冒烟测试
```
