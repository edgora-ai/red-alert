# 现代红警 Modern Red Alert

经典红警玩法的现代武器版浏览器 RTS：单人遭遇战，蓝军（玩家）vs 红军（AI）。
采矿经济、电力系统、基地建造、坦克海推进，武器装备全面现代化。

## 运行

需要一个静态文件服务器（ES Modules 不能用 file:// 打开）：

```bash
npm start          # = python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000/
```

## 玩法

- 目标：歼灭红军全部建筑与单位（或自己被歼灭）
- 经济：采矿车自动采金矿运回精炼厂，资金是唯一资源
- 电力：电厂供电，供不应求时生产减速、防御塔停摆
- 科技：兵营 → 战车工厂 → 雷达站 → 高级单位/建筑

### 操作

| 操作 | 按键 |
|---|---|
| 选择/框选 | 左键（Shift 加选） |
| 移动/攻击/采矿/设集结点 | 右键（按目标自动判断） |
| 攻击移动 | A + 左键 |
| 展开基地车 | D |
| 停止 | S |
| 出售建筑 | X |
| 编队 | Ctrl+1~3 编组，1~3 选取 |
| 相机 | 方向键 / 屏幕边缘 / 滚轮缩放 / Q E 旋转 / 小地图点击 |

灰熊→猎豹II主战坦克 · 犀牛→暴君重型坦克 · IFV→猎手弹炮合一 ·
V3→长剑巡航导弹车 · 光棱→极光粒子束坦克 · 新增幽灵武装无人机 ·

### 演示模式

`http://localhost:8000/?demo=1` 自动建造并发起进攻（可作自测）；
`&ff=N` 加载后同步快进 N tick（无头截图验证用）；
`?demo=1&scene=battle` 直接摆一场坦克遭遇战看特效。

## 技术

- 模拟层（`src/sim/`）纯逻辑零 DOM 依赖，可无头测试
- 渲染层为 Three.js 低多边形 3D（`vendor/three.module.min.js` 本地内置，离线可玩）：
  坦克底盘/履带/旋转炮塔/炮口制退器、导弹发射箱起竖、四旋翼无人机、
  电厂烟囱、核电站冷却塔、雷达旋转天线、激光棱镜、轨道炮双导轨
- 地表与战争迷雾为 Canvas 贴图，特效为叠加混合的 3D 光束/火球/爆炸闪光

## 结构

```
src/config.js     全部平衡数据（改数值调平衡都在这里）
src/sim/          纯逻辑：世界/寻路/经济/战斗/AI（不依赖 DOM）
src/render/       Three.js 渲染器/3D 模型库/输入/建造栏 UI/小地图
src/audio.js      WebAudio 合成音效
src/demo.js       演示模式（可选加载）
vendor/           three.js r160（本地化）
test/smoke.mjs    无头冒烟测试
```
